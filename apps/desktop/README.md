# @handy/desktop (en diseño)

Ejecutable para Windows, macOS y Linux con Tauri 2. Plan en `docs/03-roadmap.md` (M3).

Responsabilidades:

- Empaquetar `apps/web`.
- Acceso a archivos del usuario (proyectos, catálogos, escaneos).
- Servidor HTTP local (`http://127.0.0.1:7777`) con OpenAPI y MCP (Streamable HTTP) para que las IAs del PC usen Handy.
- Registro automático en Claude Desktop/Claude Code al instalar (opcional).
- Conversión de USDZ y otros formatos pesados fuera del navegador.
